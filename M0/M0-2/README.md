# M0-2 · 首个代码工具：相关系数计算器

对「祖传」脚本 `legacy_corr.py` 的完整重构。功能：读取 YAML 配置 → 读取 CSV 两列数据 → 手写算法计算皮尔逊相关系数 → 打印结果。

## 一、如何运行

```bash
# 推荐：用 --config 指定配置文件（相对/绝对路径均可）
python3 corr.py --config config.yaml

# 也支持位置参数
python3 corr.py config.yaml

# 省略参数时默认使用当前目录下的 config.yaml
python3 corr.py
```

配置中 `input_csv` 为相对路径时，程序**依次按「配置文件所在目录」和「当前工作目录」两种基准解析**，任意一种能找到文件即可运行。

## 二、输入文件格式要求

### config.yaml（YAML）

| 字段 | 必填 | 含义 |
|------|------|------|
| `input_csv` | ✅ | 输入数据 CSV 的路径（相对或绝对） |
| `columns.x` | ✅ | 参与计算的 x 列名 |
| `columns.y` | ✅ | 参与计算的 y 列名 |
| `task.name` | 否 | 任务名（仅标识，不参与计算） |
| `task.verbose` | 否 | `true` 打印中间量（n/mean_x/mean_y），`false` 仅打印 r。默认 `true` |

示例：
```yaml
input_csv: "sample_data.csv"
columns:
  x: "sensor_a"
  y: "sensor_b"
task:
  name: "corr_analysis"
  verbose: true
```

### 数据 CSV

- 必须为 UTF-8 编码，**首行是表头**，含 `timestamp` 等任意列均可，只要表头里存在 `columns.x` 与 `columns.y` 指定的列名。
- 参与计算的两列必须是**数值**；空值行会被跳过。
- 列名需与 yaml 中 `columns.x / columns.y` 完全一致（区分大小写、前后无空格）。

## 三、输出结果含义

程序打印到 stdout：

```
n = 40
mean_x = 49.9000000000
mean_y = 44.0000000000
r = 0.5634747255
```

| 输出 | 含义 |
|------|------|
| `n` | 参与计算的样本点数量（即两列数据的行数） |
| `mean_x` | x 列的平均值 |
| `mean_y` | y 列的平均值 |
| `r` | 两列的皮尔逊相关系数（Pearson correlation coefficient），**取值范围 [-1, 1]** |

`r` 的取值范围与解读：

| r 值 | 含义 |
|------|------|
| `r = 1` | 完全正相关：y 随 x 线性同向增大 |
| `0 < r < 1` | 正相关：两者大致同向变化，越接近 1 线性关系越强 |
| `r = 0` | 无线性相关（不代表无关，可能为非线性关系） |
| `-1 < r < 0` | 负相关：两者大致反向变化 |
| `r = -1` | 完全负相关：y 随 x 线性反向 |

> 判定依据：`r = Σ((x-mean_x)(y-mean_y)) / sqrt(Σ(x-mean_x)² · Σ(y-mean_y)²)`，即协方差除以两列标准差之积。

## 四、异常处理（可读报错，非 0 退出）

以下场景程序会向 stderr 打印 `错误: ...` 并以**非 0 退出码**结束，**不会抛 Python 栈回溯**：

| 异常场景 | 提示信息示例 |
|----------|--------------|
| 配置文件不存在 / YAML 解析失败 | `错误: 找不到配置文件: xxx` |
| 数据文件不存在 | `错误: 找不到数据文件: xxx（已尝试: ...）` |
| 空文件 / 无有效数据行 | `错误: 数据文件无有效数据行: xxx` |
| 列名不匹配 | `错误: 列名不匹配: 'xxx'，请检查 csv 表头...` |
| 除零（某列取值恒定，方差为 0） | `错误: 某列取值恒定（方差为 0），相关系数无定义` |
| 样本数不足 2 | `错误: 数据点不足...` |
