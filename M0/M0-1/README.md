# M0-1 环境搭建记录

## 这一题干了啥

简单说就是把开发环境搭起来：装好 Ubuntu，装上 ROS2、Python、C/C++ 工具链，配好 git 和 SSH，让后面写代码有地方放、能跑、能提交。看起来不难，真做起来一路都是坑。

## 本机踩坑实录（这部分最值钱）

### 坑一：BIOS 里的 Secure Boot，我一开始当成了 Security

装 Ubuntu 双系统的时候，进 BIOS 想调启动顺序，一眼看到 **Secure Boot** 这个选项。当时英文不太行，脑子里第一反应是"安全设置（security）"，觉得开着没毛病，就没去细管它。结果装完系统，开机引导各种不对劲，进系统也老出问题。

后来查了资料、问同学才知道，**Secure Boot 是"安全启动"**，跟普通的安全设置完全是两码事。双系统场景下它经常要关掉才能正常引导，跟我要的"双重系统共存"是冲突的。把它关了之后，系统才正常起来。

教训：BIOS 里全是英文，真不能靠猜。看到不认识的选项，先查清楚是干嘛的再动，不然给自己挖坑。

### 坑二：装 VS Code 和开发插件，终端报"无法定位软件包 g++"

系统终于正常了，开始装环境。我想装写 C++ 要用的编译器 `g++`，在终端里敲：

```
sudo apt install g++
```

结果直接给我甩一句 `E: Unable to locate package g++`，人直接懵了——教程里就是这么写的啊，怎么到我这就装不上。

我以为是包名打错了，又试了几遍，还是一样。后来搜了一下才发现，**新装的系统 apt 的软件源索引还是空的**，得先让它去拉一遍：

```
sudo apt update
```

更新完再装 g++，一下就装上了。就这么个小事卡了我好一会儿，纯粹是"没先 update"的问题。以后装啥软件，第一件事先 `sudo apt update`。

### 坑三：WSL 默认装进了 C 盘

环境继续往下配的时候发现，装好的 WSL 发行版默认是在 **C 盘**的。可 C 盘本来就没多少地方了，我不想让它越占越多。后来用 WSL 自带的"导出→导入"把它整个挪到了 D 盘，C 盘一下清爽了。

### 坑四：ROS2 官方源连不上，换成清华镜像

装 ROS2 的时候，官网给的那个软件源在国内根本连不通，一直超时，装到一半就卡住。试了一圈发现国内镜像（清华的）能用，就把软件源换成镜像，瞬间就装好了。

## 通过什么方法 / 查了什么资料

- 主要看官方文档：Ubuntu、ROS2、WSL 官网那几篇，跟着一步步来
- 报错就直接复制到搜索引擎，看别人怎么解决的
- 卡住的时候问了同学，也找 AI 帮忙定位问题
