# M3｜ROS2 智能车仿真与导航

M3 的四道题是一条连续工程链，建议严格按顺序完成：

```text
M3-1 车能动、里程计可测
  ↓ 车模、控制器、TF、odom
M3-2 激光 SLAM 建出可导航地图
  ↓ world、map.pgm、map.yaml
M3-3 在该地图上定位并自主导航
  ↓ Nav2 配置、一键 launch、调优数据
M3-4 导航途中加入动态障碍并比较规划器
```

## 学习原则

1. 先算再写：转弯半径、运行时长、地图分辨率等先给出理论依据。
2. 一次只验证一个环节：模型 → 控制 → 数据 → 统计 → 可视化。
3. 不用“看起来不错”代替数据：每题都保留原始记录和定量结果。
4. 不隐藏失败：失败现象、日志、原因和修复过程都是交付物的一部分。
5. 自动生成目录（`build/`、`install/`、`log/`）不提交到 Git。
